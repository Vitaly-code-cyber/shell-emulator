# Эмулятор командной оболочки (вариант №16)

Практическая работа №1 по дисциплине «Конфигурационное управление».

## Общее описание

Проект представляет собой эмулятор командной оболочки UNIX-подобной
операционной системы. Эмулятор работает в форме консольного
приложения (CLI): он показывает приглашение к вводу, разбирает
введённую строку на команду и аргументы и выполняет её.

Реализованные этапы:

1. **REPL** — прототип с диалогом и командами-заглушками.
2. **Конфигурация** — параметры командной строки, журналирование
   событий в формате XML и выполнение стартовых скриптов.

## Описание всех функций и настроек

### Параметры командной строки

| Параметр | Назначение | По умолчанию |
|----------|-----------|--------------|
| `--vfs ПУТЬ` | Путь к физическому расположению VFS (ZIP-архив) | не задан |
| `--log ПУТЬ` | Путь к лог-файлу в формате XML | журнал не ведётся |
| `--script ПУТЬ` | Путь к стартовому скрипту эмулятора | не задан |

При запуске эмулятор печатает отладочный список всех заданных
параметров.

### Команды

| Команда | Назначение | Аргументы |
|---------|-----------|-----------|
| `ls` | Заглушка: печатает имя команды и аргументы | Произвольные |
| `cd` | Заглушка: печатает имя команды и аргументы | Не более одного |
| `exit` | Завершение работы эмулятора | Отсутствуют |

### Приглашение к вводу

Приглашение содержит имя VFS и имеет вид `minimal$ `. Имя берётся из
имени файла образа VFS без расширения; если параметр `--vfs` не
задан, используется значение `vfs`.

### Журнал событий

Если задан параметр `--log`, каждый вызов команды сохраняется в
XML-файл. Журнал перезаписывается после каждого события, поэтому
остаётся корректным XML-документом даже при аварийном завершении.

```xml
<?xml version='1.0' encoding='utf-8'?>
<session user="user" started="2026-09-18T13:48:38">
  <event time="2026-09-18T13:48:38" user="user" command="ls" status="ok">
    <arguments>-l /etc</arguments>
  </event>
  <event time="2026-09-18T13:48:43" user="user" command="wget"
         status="error">
    <arguments />
    <error>wget: команда не найдена</error>
  </event>
</session>
```

Каждое событие дополнительно содержит имя пользователя реальной
операционной системы и, при неудачном выполнении, сообщение о
возникшей ошибке.

### Стартовые скрипты эмулятора

Стартовый скрипт — текстовый файл с расширением `.vsh`, содержащий
по одной команде эмулятора в строке. Пустые строки и строки,
начинающиеся с `#`, пропускаются.

При выполнении скрипта на экран выводится как ввод, так и вывод
команд, что имитирует диалог с пользователем. **Выполнение
останавливается на первой ошибке**: эмулятор печатает имя файла,
номер строки и описание ошибки, после чего завершает работу с кодом
возврата 1.

Готовые скрипты находятся в папке `startup`:

* `stage2_basic.vsh` — успешное выполнение всех команд;
* `stage2_error.vsh` — остановка на первой ошибке.

### Обработка ошибок

Сообщения об ошибках выводятся в стандартный поток ошибок в виде
`ошибка: <описание>`. В интерактивном режиме диалог продолжается, при
выполнении скрипта — прекращается.

Предусмотрены ошибки:

* неизвестная команда;
* неверное число аргументов команды;
* недоступный или отсутствующий файл стартового скрипта;
* неизвестный параметр командной строки.

## Сборка проекта и запуск тестов

Внешние зависимости не требуются, достаточно Python 3.10 и новее.

```bash
./run.sh                       # запуск эмулятора
make run ARGS='--log build/s.xml'   # запуск с параметрами
make test                      # запуск модульных тестов
make clean                     # удаление временных файлов
```

Скрипты реальной ОС для проверки эмулятора находятся в папке
`scripts`:

```bash
./scripts/stage2_defaults.sh   # каждый параметр по отдельности
./scripts/stage2_full.sh       # все параметры сразу
./scripts/stage2_errors.sh     # обработка ошибок
```

## Примеры использования

### Интерактивный режим

```text
$ ./run.sh
=== Параметры запуска эмулятора ===
Путь к VFS: не задан
Путь к лог-файлу: не задан
Путь к стартовому скрипту: не задан
===================================
vfs$ ls -l /etc
ls: аргументы = [-l, /etc]
vfs$ cd /etc /tmp
ошибка: cd: ожидается не более одного пути
vfs$ wget
ошибка: wget: команда не найдена
vfs$ exit
Выход из эмулятора.
```

### Выполнение стартового скрипта

```text
$ ./run.sh --vfs build/minimal.zip --script startup/stage2_error.vsh
minimal$ ls /var
ls: аргументы = [/var]
minimal$ wget http://example.com
ошибка: startup/stage2_error.vsh:4: wget: команда не найдена
        (выполнение остановлено)
```
