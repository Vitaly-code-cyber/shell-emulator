# Эмулятор командной оболочки (вариант №16)

Практическая работа №1 по дисциплине «Конфигурационное управление».

## Общее описание

Проект представляет собой эмулятор командной оболочки UNIX-подобной
операционной системы. Эмулятор работает в форме консольного
приложения (CLI): он показывает приглашение к вводу, разбирает
введённую строку на команду и аргументы и выполняет её.

На первом этапе реализован минимальный прототип: диалог с
пользователем поддерживается, команды `ls` и `cd` являются
заглушками и печатают собственное имя вместе с аргументами.

## Описание всех функций и настроек

### Команды

| Команда | Назначение | Аргументы |
|---------|-----------|-----------|
| `ls` | Заглушка: печатает имя команды и аргументы | Произвольные |
| `cd` | Заглушка: печатает имя команды и аргументы | Не более одного |
| `exit` | Завершение работы эмулятора | Отсутствуют |

### Приглашение к вводу

Приглашение содержит имя VFS и имеет вид `vfs$ `. На первом этапе
используется имя по умолчанию, на последующих — имя загруженного
образа VFS.

### Обработка ошибок

Сообщения об ошибках выводятся в стандартный поток ошибок в виде
`ошибка: <описание>`. Диалог при этом не прерывается.

Предусмотрены ошибки:

* неизвестная команда;
* неверное число аргументов команды.

## Сборка проекта и запуск тестов

Внешние зависимости не требуются, достаточно Python 3.10 и новее.

```bash
./run.sh          # запуск эмулятора
make run          # то же самое через Makefile
make test         # запуск модульных тестов
make clean        # удаление временных файлов
```

## Примеры использования

```text
$ ./run.sh
vfs$ ls -l /etc
ls: аргументы = [-l, /etc]
vfs$ cd
cd: аргументы = [нет]
vfs$ cd /etc /tmp
ошибка: cd: ожидается не более одного пути
vfs$ wget
ошибка: wget: команда не найдена
vfs$ exit
Выход из эмулятора.
```
