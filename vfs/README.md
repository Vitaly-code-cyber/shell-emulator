# Исходные образы VFS

В репозитории хранятся не ZIP-архивы, а исходные деревья файлов:
архивы и двоичные файлы являются артефактами сборки и в системе
контроля версий не размещаются.

| Каталог | Назначение |
|---------|-----------|
| `minimal` | Минимальный образ: один файл в корне |
| `simple` | Несколько файлов в корневом каталоге |
| `deep` | Не менее трёх уровней вложенности файлов и папок |

Двоичные данные хранятся в кодировке base64 в файлах с суффиксом
`.b64` (например, `logo.png.b64`). При загрузке образа эмулятор
снимает суффикс и восстанавливает исходные байты в памяти.

Сборка ZIP-образов в каталог `build`:

```bash
make vfs
python3 tools/build_vfs.py deep   # собрать только один образ
```
